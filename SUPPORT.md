# Community beta support

We use [GitHub Issues](https://github.com/blankboxcode/blankbox-community/issues/new/choose) for installation questions, bugs, feedback and beta test results. Read [Feedback and issues](FEEDBACK.md) before posting. Support is best effort, with no guaranteed response time.

For the published beta.8 installation, start with the exact [Start Here guide](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/START-HERE.md), then the [Linux](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/guides/LINUX.md), [Docker](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/guides/DOCKER.md) or [experimental Windows](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/guides/WINDOWS.md) instructions. The [wiki](https://github.com/blankboxcode/blankbox-community/wiki) collects additional explanations and small checks you can try.

If setup fails, retain the extracted package and your existing data. A retry does not require deleting the library. If an operation may have changed data, keep the original source and recovery material while you review the result. Follow the [Recovery guide](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/RECOVERY.md) for a new empty restore destination; a recovery point cannot recreate missing linked originals.

Include the installed version, device/OS, installation method, steps, expected result and actual result. Share only a short redacted error excerpt if needed. Public support does not require your recovery key, provider credentials, catalog, backups or media files.
