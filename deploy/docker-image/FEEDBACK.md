# Feedback and issues

We welcome feedback from everyone using Blank Box Community. Tell us what worked, what was confusing and what would help you organize or enjoy your collection.

[Open a report](https://github.com/blankboxcode/blankbox-community/issues/new/choose) or [search existing issues](https://github.com/blankboxcode/blankbox-community/issues).

## Choose a report

| Report | Use it for |
| --- | --- |
| Bug report | Something failed or behaved differently from what you expected. |
| Setup help | Installation, sign-in, source folders, networking or recovery instructions are unclear. |
| Feedback or feature idea | A workflow could be clearer, or you have an idea for a future change. |
| Share your experience | Describe using Blank Box on your devices, with your storage or as part of your everyday routine. |

For a bug or setup question, include the exact Blank Box version, operating system, installation method, browser/device, action, expected result and actual result. Include a short reproduction using sample names if possible. If you do not know a detail, say so rather than guessing.

Search for an existing report first. If you find the same problem, add your version and result there. Keep a different problem in a separate issue so we can follow it through a fix.

## Keep your household private

Issues are public. Use names such as `Sample Album` or `Example Book`, and replace private paths with `/path/to/source`. Do not upload catalogs, backups, media, recovery keys, passwords, provider tokens or session files. Crop or redact screenshots and log excerpts before posting; logs can contain titles, paths and addresses. We do not need your actual library to understand a report.

For recovery questions, report the step and outcome rather than the underlying household records.

## What to expect

We review reports on a best-effort basis. We may ask for a smaller example or missing environment details, link duplicates, or defer an idea while we work on other improvements. There is no guaranteed response time or commitment to implement every suggestion. A closed duplicate or deferred request does not erase the feedback.

Find the installation packages on the [Downloads page](https://github.com/blankboxcode/blankbox-community/releases/tag/v0.1.0-beta.8) and everyday guidance in the [wiki](https://github.com/blankboxcode/blankbox-community/wiki). Windows remains experimental. Use the guides shipped with your installed version for its exact commands.
