# Blank Box Community support

Use [GitHub Issues](https://github.com/blankboxcode/blankbox-community/issues/new/choose) for installation questions, bugs, feedback and experiences. Join the [Discord community](https://discord.com/invite/fD8k4sn9sk) for conversation and announcements. Read [Feedback and issues](FEEDBACK.md) before posting. Support is best effort, with no guaranteed response time.

Start with the README's [ZIP installation](https://github.com/blankboxcode/blankbox-community/blob/main/README.md#install-from-a-zip) or [Docker quick start](https://github.com/blankboxcode/blankbox-community/blob/main/README.md#install-with-docker). The [wiki](https://github.com/blankboxcode/blankbox-community/wiki) explains everyday use, collections, networking and recovery.

| You need help with | Read |
| --- | --- |
| Installation and first sign-in | [Getting started](https://github.com/blankboxcode/blankbox-community/wiki/Getting-Started) |
| Connecting a phone or another computer | [Home-network access](https://github.com/blankboxcode/blankbox-community/wiki/Access-on-Your-Home-Network) |
| Adding physical copies, files or a connected server | [Using your library](https://github.com/blankboxcode/blankbox-community/wiki/Using-Your-Library) |
| Groups, shelves and local activity | [Organizing collections](https://github.com/blankboxcode/blankbox-community/wiki/Organizing-Collections) |
| Reference databases and title matching | [Offline metapacks](https://github.com/blankboxcode/blankbox-community/wiki/Offline-Metapacks) |
| Protecting or restoring your library | [Backup and recovery](https://github.com/blankboxcode/blankbox-community/wiki/Backup-and-Recovery) |

For installation details, use the current [Linux](https://github.com/blankboxcode/blankbox-community/blob/main/guides/LINUX.md) or [Docker](https://github.com/blankboxcode/blankbox-community/blob/main/guides/DOCKER.md) guide. The separate [experimental Windows](https://github.com/blankboxcode/blankbox-community/blob/v0.1.0-beta.8/guides/WINDOWS.md) download retains its own older guide.

If setup fails, retain the extracted package and your existing data. A retry does not require deleting the library. If an operation may have changed data, keep the original source and recovery material while you review the result. Follow the current [Recovery guide](https://github.com/blankboxcode/blankbox-community/blob/main/RECOVERY.md) for a new empty restore destination; a recovery point cannot recreate missing linked originals.

Include the installed version, device/OS, installation method, steps, expected result and actual result. Share only a short redacted error excerpt if needed. Public support does not require your recovery key, provider credentials, catalog, backups or media files.
